# Student Marks Manager – Python

A menu-driven Python application for managing student records and marks.

## 📌 Project Overview

Student Marks Manager is a console-based Python application that allows users to manage student marks through a simple interactive menu.

The project was built to practice Python fundamentals and develop problem-solving skills through a practical application.

## ✨ Features

- View all student records
- Add a new student
- Update student marks
- Delete a student
- Search for a student
- Validate user input
- Check student pass/fail status
- Handle invalid menu choices and marks
- Prevent duplicate student names

## 🛠️ Technologies Used

- Python
- Dictionaries
- Functions
- Loops
- Conditional Statements
- Exception Handling
- Input Validation
